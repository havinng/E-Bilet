# 🎫 E-Bilet Otomasyon Uygulaması

Java ve Eclipse ortamında geliştirilmiş, seyahat konforunu artırmayı hedefleyen masaüstü e-bilet ve koltuk otomasyon sistemi.

## 🌟 Proje Vizyonu ve Öne Çıkan Özellikler
Geleneksel biletleme sistemlerinin ötesine geçen bu yenilikçi proje; seyahat konforunu artırmayı ve yolcuların beklentilerine uygun, huzurlu bir ortam yaratmayı hedeflemektedir.

* 👶 **Akıllı Koltuk Seçimi & Renk Kodlaması:** Bebekli ailelerin seyahat süreçlerini optimize etmek amacıyla, bebekli koltuklar seçim ekranında özel bir renk koduyla dinamik olarak işaretlenir.
* 🤫 **Sese Duyarlı Yolcu Yönlendirmesi:** Sessiz ve huzurlu bir yolculuk talep eden yolcuları bu dinamik haritaya göre yönlendirerek potansiyel gerginliklerin önüne geçer.
* 🎟️ **Biletleme & Rezervasyon:** Kullanıcı dostu arayüz üzerinden hızlı bilet alma ve koltuk seçimi.
* ⚙️ **Nesne Yönelimli Mimari (OOP):** Temiz, modüler ve sürdürülebilir Java altyapısı.
  
## 🛠️ Kullanılan Teknolojiler

* **Dil:** Java
* **Geliştirme Ortamı (IDE):** Eclipse
